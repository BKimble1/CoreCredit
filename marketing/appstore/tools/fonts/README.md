`Inter-SemiBold.ttf` renders the status-bar clock and the battery numerals,
matched to the reference capture's ink height, stroke weight and tabular digit
advance, and the marketing subtitle.

`Inter-ExtraBold.ttf` (Inter 4.1) renders the marketing headline. Both weights,
their size, tracking, leading and left margin were fitted to the copy already
set on the template, so copy reset with `copy_layer.py` lands where the template
put it.
